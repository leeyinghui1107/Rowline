# 05 · 美术规格书（Sprite Sheet Spec）

> 用途：指导自制美术替换占位图，同时**保证渲染代码与行为规格不变**。
> 原始美术受版权保护（`REPORT.md` §5），本规格书只描述**几何与索引契约**，不含任何原作素材。

---

## 1. 核心约束：索引布局不可改

渲染层用固定公式取样（`reference/c-impl/wl_render.c`）：

```
srcX = cellValue * 36 + spriteSet * 288
srcY = 225                 (常量)
size = 36 x 36
```

因此美术**只需**提供一张 **576 × 586** 的图集，并把 14 个球/形精灵放在指定的格子里。

| 列区间 | 精灵集 | 语义 |
|---|---|---|
| 0 | 0 (球体) | **空格**底板（空 cell 的底纹） |
| 1 – 7 | 0 (球体) | 7 色球体，颜色 1..7 |
| 8 | 1 (多边形) | **空格**底板 |
| 9 – 15 | 1 (多边形) | 7 色多边形，颜色 1..7 |

> **`cellValue` 即列号**：`cellValue = 0` 表示空格，`1..7` 表示颜色。
> 精灵集开关（`UseFigures`）只是给源 X 加上 288，**不改变颜色与格子的对应关系**。

## 2. 画布规格

| 项 | 值 | 说明 |
|---|---|---|
| 画布尺寸 | **576 × 586 px** | 与原作图集同尺寸，便于逐格对照 |
| 色彩格式 | 24 位 RGB（PNG 或 BMP） | SDL2 核心可直接加载 BMP，无需 SDL2_image |
| 背景 | `#C0C0C0`（Win95 按钮面） | 与空格底板一致 |
| 网格 | 16 列 × 10 行，步长 **36 px** | 仅第 5 行（y = 225..261）被采样 |
| 精灵尺寸 | **32 × 32 px**，在 36 px 格内**居中**（四周各留 2 px） | 渲染时目标格也是 36 px，含 2 px 内缩 |
| 采样带 | `y = 225 .. 260` | 高度正好 36 px |

> **为什么是 36 而不是 32**：渲染目标也是 36 px，源精灵 32 px 居中，
> 这样相邻格子之间天然留出 4 px 间隙，且不会在缩放时溢出邻格。
> **改这个值必须同步改 `WL_SRC_STEP` / `WL_SPRITE_INSET` / `WL_CELL_PX`。**

## 3. 命名与坐标约定

| 约定 | 规则 |
|---|---|
| 颜色索引 | `colorId` ∈ 1..7，**跨两种精灵集保持一致**（颜色 3 在球体和多边形里都是同一个颜色） |
| 精灵格坐标 | `col = colorId + set * 8`，`set` ∈ {0,1} |
| 原点 | 每格的左上角为 `x = col * 36, y = 225` |
| 精灵原点 | `x + 2, y + 2`（36 px 格的左上角 + 2） |
| 命名建议 | `ball_01_green.png`、`fig_01_green.png`、`cell_empty.png` |

## 4. 调色板

从原作图集直方图中提取的 7 色基色（供占位图与新美术对齐色相；**注意这些是本作自定色板，不属于原作资产**）：

| colorId | 名称 | RGB | 十六进制 |
|---|---|---|---|
| 1 | green | (0, 160, 0) | `#00A000` |
| 2 | blue | (0, 0, 192) | `#0000C0` |
| 3 | cyan | (0, 192, 192) | `#00C0C0` |
| 4 | magenta | (192, 0, 192) | `#C000C0` |
| 5 | red | (192, 0, 0) | `#C00000` |
| 6 | yellow | (192, 192, 0) | `#C0C000` |
| 7 | maroon | (128, 0, 0) | `#800000` |

**可访问性要求**

- 相邻颜色必须在**灰度**下可区分（游戏支持灰度重着色路径，原作有 `Color_ToGray`）。
  按上表求亮度：green 106 / blue 18 / cyan 130 / magenta 73 / red 38 / yellow 139 / maroon 21。
  ⚠️ **blue(18) 与 maroon(21) 几乎同灰度**——若保留灰度可读性需求，需调整二者的明度差。
  建议把 maroon 提到 `#A03030`（亮度 ~52）或把 blue 提到 `#3030C0`（亮度 ~38）。
- 色盲友好：不要仅用红/绿区分；形状差异（球体 vs 多边形）已提供第二维度。

## 5. 形状规格（多边形精灵集）

原作的多边形组中**每种颜色使用固定形状**，本规格沿用该约定（保持可识别性）：

| colorId | 形状 | 几何 |
|---|---|---|
| 1 | 方形 | 24 × 24 实心方，居中 |
| 2 | 方形 | 同上 |
| 3 | 菱形 | 对角 28 × 28 的菱形 |
| 4 | 上三角 | 底边 26、高 24 |
| 5 | 下三角 | 顶边 26、高 24 |
| 6 | 右三角 | 左边 24、高 24 |
| 7 | 右三角 | 同上 |

多边形统一带 1 px 高光描边（亮度 ×1.4），与球体的立体感保持一致。

## 6. 制作与交付流程

```bash
# 1) 生成占位图 + 美术参考底图
make sheet
#   -> assets/sheet/rowline_sheet.png        （占位图，可直接跑）
#   -> assets/sheet/rowline_sheet.bmp        （SDL2 直接加载）
#   -> assets/sheet/rowline_sheet_guide.png  （网格 + 采样带标记）

# 2) 美术在 rowline_sheet_guide.png 上作画，或单独出图后由工具合成

# 3) 替换 assets/sheet/rowline_sheet.png / .bmp

# 4) 验证：布局门 + 差分门都必须通过
make test
```

### 6.1 自检清单

- [x] 画布严格 576 × 586 px
- [x] 采样带 `y = 225..260` 内，第 0、8 列是**空格底板**且不透明
- [x] 球体严格 32 × 32 px（实测包围盒 2..33），在 36 px 格内居中（四周 2 px）；
      多边形略小（3..33），避免尖角贴边
- [x] 精灵**不越界**到相邻格（相邻格像素必须完全透明或为底板色）
- [x] 7 种颜色在球体集与多边形集中**一一对应**（同一 colorId 同色）
- [x] 缩放到 200% / 300% / 400% 仍无模糊边缘（`@2x`–`@4x` 为重新绘制）
- [x] 深色主题下的空格底板可见（`board_cell` 为浅灰，空格板保持不透明）
- [x] 导出后跑 `make test` 全绿

### 6.2 主题化扩展（可选，不影响契约）

若要支持深色主题，**只替换空格底板**即可，格子索引不变：

| 主题 | 空格底板 | 建议 |
|---|---|---|
| 经典 | `#C0C0C0` | 保持原作观感 |
| 深色 | `#2B2B2B` | 描边 `#3C3C3C` / `#1E1E1E` |

实现方式：追加一组底板精灵到图集的**未使用区域**（例如 y = 0..224 的空白带），
并在 `wl_render.c` 里按主题选择不同的 srcY。索引契约不变。

## 7. 占位图 vs 最终美术

| 版本 | 用途 | 状态 |
|---|---|---|
| `assets/sheet/rowline_sheet.png` / `.bmp` | 占位图，程序开箱可跑 | 已生成（程序化球体 + 多边形） |
| `assets/sheet/rowline_sheet_guide.png` | 美术参考底图 | 已生成 |
| 最终美术 | 替换占位图 | **待制作**（或外包） |

占位图已按 §1 的索引契约生成，可直接作为"是否对齐"的基准：
把新美术叠在占位图上，凡是球体中心不重合即说明索引错位。
