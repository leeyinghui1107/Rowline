# 04 · 复刻 / 重新设计决策矩阵

> 决策原则：**玩法等价优先，外观等价其次，实现等价最低。**
> 对目标程序而言，"1:1 复刻"仅指**外部可观测行为一致**，不指复制其实现。

---

## 1. 判定准则

| 档位 | 判据 | 验收方式 |
|---|---|---|
| **A · 1:1 复刻** | 外部行为必须逐位一致；差异即缺陷 | 黑盒差分测试 + 存档文件字节级比对 |
| **B · 行为等价重写** | 玩法/数据/交互一致，实现自由 | 规则用例全通过 + 存档可互操作 |
| **C · 体验保留的再设计** | 保留用户价值，改变实现或表现 | 人工评审 + 关键指标不劣化 |
| **D · 移除** | 原作有、本版不做 | 显式记录并说明理由 |

## 2. 决策矩阵

### 2.1 玩法与规则

| # | 元素 | 档位 | 理由 | 验收要点 |
|---|---|---|---|---|
| F-01 | 棋盘 9×9 | **A** | 数值简单、无成本，直接照搬 | 截图比对格数与原点 |

## 3. 汇总

| 档位 | 数量 | 占比（按条目） | 代表项 |
|---|---|---|---|
| **A · 1:1 复刻** | 9 | 约 21% | 棋盘尺寸、颜色数、阈值=5、8 方向、阻挡规则、结束条件、精灵索引布局、默认榜单 |
| **B · 行为等价重写** | 20 | 约 47% | 路径算法、补球、分值、动画、存档布局、INI 语义 |
| **C · 体验保留再设计** | 13 | 约 30% | 边框、侧栏、控件、主题、字体、PRNG、存储位置 |
| **D · 移除** | 8 | 约 19% | 调色板、Logo、反作弊掩码、损坏编码、死字符串、Win32 平台本身 |

> **净效果**：玩法 100% 等价，外观约 30% 等价（且刻意降级以规避著作权），实现 0% 等价。

## 4. 逐项风险

| 风险 | 等级 | 说明 | 缓解 |
|---|---|---|---|
| 消除集合在等价实现下出现偏差 | **高** | 路径搜索顺序影响等长路径的选取，进而影响后续局面 | 用原作存档 + 固定随机种子做**回放差分**：同一初始局面、同一操作序列，消除集合必须逐步一致 |
| 分数公式未确认导致"手感"漂移 | **高** | 直接影响可玩性观感 | `BB-G11` 至少 15 次观测建表；上线前做 A/B 主观评审 |
| 补球时机差异引发连锁偏差 | 中 | 影响长期局面演化 | 差分回放 |
| 侧栏/棋盘公式重写后布局不匹配 | 中 | — | 以 3 种窗口尺寸做回归截图 |
| 存档互操作失败导致老用户高分丢失 | 中 | — | 写一次性导入器 + 导出工具 + 回归样例 |
| 自制美术与 36 px 网格不匹配 | 中 | 缩放会破坏精灵对齐 | 美术交付规范：严格 36 px 网格、32 px 实际图形、居中 2 px |
| 俄文提示缺失影响俄语区用户 | 低 | — | 后续补 i18n |

## 5. 实施里程碑与验收门

| 里程碑 | 交付 | 验收门（Gate） |
|---|---|---|
| **M1 骨架** | 空棋盘 + 渲染管线 + 布局公式 | 窗口缩放到 640×480 / 1024×768 / 1920×1080，棋盘与侧栏无重叠、位置与原作一致 |
| **M2 玩法** | 选球、移动、连通判定、消除、补球 | `BB-G01..G12` 全通过；与原作**消除集合**逐步一致（差分回放） |
| **M3 计分与结束** | 分值、关卡、结束流程 | `BB-G13/G14/G15` 通过 |
| **M4 持久化** | INI 读写、高分榜、导入器 | 能读取原作 INI 与注册表数据；往返一致 |
| **M5 表现** | 自制美术、动画、HUD、主题 | 3 种窗口尺寸 + 深浅主题截图评审通过 |
| **M6 交付** | 跨平台构建、文档、i18n 骨架 | Windows + macOS + Linux 构建通过；帮助手册可用 |

**每道门的强制产物**：黑盒用例执行记录 + 与原作的差分报告 + 已知偏差清单（附处置结论）。

## 6. 明确不做的事

| 不做 | 原因 |
|---|---|
| 分发原作位图 / Logo / 图标 / 名称 | 著作权（`REPORT.md` §5） |
| 把反编译伪代码写入产品 | 仅作研究参考 |
| 复刻 XOR 掩码校验 | 无安全收益，且是原作实现 |
| 保留损坏的俄文编码 | 技术债 |
| 追求 Win32 位级渲染一致 | 与跨平台目标冲突，且以复刻规则为先 |
| 加入在线排行榜 / 账号 | 超出重构范围，且引入隐私与合规成本（若做，需单独立项） |
